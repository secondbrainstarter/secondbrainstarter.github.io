Always Link: How Links Turn a Note Collection into a Second Brain

04. August 2026 · Method · English

Most note systems fail at an invisible problem: they collect diligently, but the notes stay islands. Each file sits alone, and whoever looks for it later first has to remember that it exists at all. Linking is the one rule that turns a filing system into a network — and that is exactly the difference between a folder full of files and a second brain.

A note without a link is an island. You only find it if you know precisely that it exists — and a few weeks in, that is almost never the case. A link is a path: it leads from what you are thinking right now to what you already know. The more paths exist in your system, the more often you stumble over your own ideas — exactly when you need them. That is why the third rule of the Mini-Vault is: “Always link — every note links at least one other note.” That is how a collection becomes a network, and the network is the second brain.

The duty: one link per note, when you create it. Not later, not “when I have time” — later never happens. The permanent note template turns this into a checklist: “At least 1 link set.” One single link is enough as the required minimum; everything else is a bonus. Keep the rule, and after 100 notes you have a network with at least 100 connections — and with it, something that search alone never delivers: paths you did not search for.

Three link types cover almost everything:

  • “What I already know”: The most important link. A new idea points to the related idea you have already captured — knowledge grows in one place instead of scattering.
  • Context links: Project notes link the permanent notes they build on; daily notes link the project you are working on. Every note shows what it belongs to.
  • Waypoint links: Links to notes that do not exist yet. Obsidian creates them on first click — the link is a promise to yourself that this topic will get a place.

The purpose is reuse. A note you never open again is dead weight — no matter how well it is written. Links make reuse possible, and Obsidian helps automatically: the backlink view shows you, for every note, what points to it. Old notes become context for new thoughts without you having to do anything. Whoever never captures the same idea twice not only saves time — at some point they notice that the system starts thinking along.
